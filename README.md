# WiiTube
vibecoded wii u youtube client because the official youtube client for the wii u is a pain in the ahh

This youtube client is simple and meant to be simple for the wii u

Things needed :
1) a modded wii u with aroma
2) a youtube data v3 api key
3) internet connectivity

to setup simply:
1) extract the zip file
2) copy the wiiu folder to the root of your wii u sdcard
3) go inside the wiiu folder then apps and then wiitube
4) change the content of api.txt to your youtube data v3 api key
5) save
after that you should be good to go
